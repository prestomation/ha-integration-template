API reference

Every surface an integration or automation can build on, generated from the shipping code. Labels and descriptions are the same strings Home Assistant shows in its own dialogs, so this page and the UI never disagree.

New to this? Start with the integration guide, which walks through calling a service and reacting to its event.

Surface coverage​

Every kind of integration surface Home Assistant offers, and the status of each one here. The rows that say not applicable or deferred are the useful ones: a list of what exists cannot tell you what is missing.

SurfaceStatusNotes
Actions (services)PublishedEvery operation that mutates or exports data ships as an example_integration.* service, which is the interoperability contract.
Bus eventsPublishedEvery observable state change fires an example_integration_<noun>_<verb> event, built by a pure function so the shipped payload and the documented one are the same object.
Device triggersNot applicableThe example integration owns one service device grouping its entities, with no per-item devices for a trigger to hang off.
Device conditionsNot applicableItem state is readable from the per-item sensor, so a condition platform would add a second way to ask one question.
Device actionsNot applicableThe services cover every operation and take an item id directly.
Entity platformsPublishedA sensor platform: one total sensor plus one per item, the usage surface as opposed to the admin panel.
Entity attributesPublishedThe total sensor carries the summed value, so an automation can read it without calling a service.
Config entry optionsNot applicableThe example feature has nothing to configure, so there is no options flow.
Config flowPublishedA single-instance UI setup flow, with no YAML configuration.
Websocket commandsInternalA latency optimization for the panel and card, delegating to the same store methods the services use.
HTTP routesInternalOne static path serving the built panel and card bundles.
DiagnosticsPublishedThe config entry supports a diagnostics download for bug reports.
Reauth / reconfigure flowsNot applicableStorage is local and needs no credentials to re-establish.
Repairs / issue registryDeferredNothing in the example feature can enter a state a user must be told to fix; add a row here when something can.
DiscoveryNot applicableThere is no device or service on the network to discover.

Actions​

Every operation that changes or exports data is a Home Assistant action, so automations, scripts, voice assistants and other integrations all reach it the same way. Guard each call with hass.services.has_service("example_integration", "<action>") so your integration still works when this one is not installed.

Events​

The integration fires a bus event for every observable state change. Names follow example_integration_<noun>_<verb>. For when each one fires in context, and worked automations, see the events guide.

EventFires whenPayloadAdds
example_integration_item_createdAn item was added.item
example_integration_item_updatedAn item's name or value changed.itemchanged_fields
example_integration_item_deletedAn item was removed. The payload is its last-known snapshot.item

Payloads​

Events sharing a payload shape are interchangeable in one automation template. Per-event additions from the table above merge onto these.

Item payload​

Carried by example_integration_item_created, example_integration_item_updated, example_integration_item_deleted.

FieldTypeNotes
item_idstrStable id, anchored across renames.
namestrThe item's display name at the time of the event.
valueintThe item's numeric value at the time of the event.

Entities​

The integration's state is readable as ordinary entities, so most automations never need to call an action to find something out.

sensor​

Entities: Total items (total_items).

State attributes:

FieldTypeNotes
total_valueintSum of every item's value, on the total sensor.

Errors​

A rejected action raises a localized Home Assistant error. The key is stable; the message shown is in the user's language.

KeyEnglish message
invalid_item{error}
item_not_foundItem not found: {item_id}
not_loadedThe Example Integration is not loaded.
